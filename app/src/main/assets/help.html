1. התקנת Shizuku והגדרות ראשוניות (פעם אחת בלבד)

מערכת ההפעלה אנדרואיד חוסמת אפליקציות רגילות מלשנות הגדרות מודם (כגון נעילת דור 5G / 4G / 3G / 2G או הפעלת מצב טיסה) ללא הרשאות מערכת. שירות Shizuku מעניק לאפליקציה הרשאות ברמת ADB Shell באופן בטוח וללא צורך בפריצת Root. את השלבים הבאים מבצעים פעם אחת בלבד בהתקנה הראשונה:

שלב א׳: התקנת Shizuku וחיבור ל-Wi-Fi
  1. התקן את אפליקציית Shizuku מחנות Google Play (מאת RikkaApps).
  2. חבר את המכשיר לרשת Wi-Fi פעילה (חובה לצורך הפעלת ניפוי שגיאות אלחוטי).
שלב ב׳: פתיחת אפשרויות מפתחים (Developer Options)
  1. היכנס ב-Settings (הגדרות) אל About phone (אודות הטלפון).
  2. לחץ 7 פעמים ברצף על Build number (במכשירי Xiaomi/MIUI/HyperOS לחץ 7 פעמים על OS version / MIUI version) עד להופעת ההודעה "You are now a developer!".
שלב ג׳: הגדרות אבטחה מיוחדות (חשוב ב-Xiaomi / POCO / Redmi)

היכנס אל Settings ➔ Additional settings ➔ Developer options והפעל את 3 המתגים הבאים:

  • USB debugging (ניפוי שגיאות USB).
  • Wireless debugging (ניפוי שגיאות אלחוטי).
  • USB debugging (Security settings) — מתג חובה במכשירי שיאומי כדי לאפשר שינוי הגדרות רדיו מרחוק.
שלב ד׳: צימוד ראשוני (Pairing) והענקת הרשאה
  1. פתח את Shizuku ולחץ על Pairing תחת Start via Wireless debugging.
  2. היכנס למסך Wireless debugging ולחץ על Pair device with pairing code — יופיע קוד בן 6 ספרות.
  3. משוך מטה את וילון ההתראות, לחץ על התראת Shizuku והקלד את הקוד בן 6 הספרות.
  4. חזור לאפליקציית Shizuku ולחץ על Start עד שיופיע Shizuku is running.
  5. פתח את Cellular RT Monitor ואשר בחלונית שתקפוץ Allow all the time.

2. הפעלת הממשק מול Shizuku לאחר הפעלה מחדש (Restart)

מכיוון ששירות Shizuku רץ בזיכרון העבודה (RAM) של המכשיר, כל אתחול (Restart) או כיבוי והדלקה של הטלפון עוצר את השירות. בפתיחת האפליקציה לאחר אתחול, תופיע אוטומטית חלונית התראה עם קיצורי דרך מהירים. אין צורך לבצע שוב צימוד (Pairing) או להזין קוד! בצע רק את 4 הפעולות המהירות הבאות (כ-10 שניות):

1. חיבור ל-Wi-Fi

וודא שהטלפון מחובר לרשת Wi-Fi (או נקודה חמה מטלפון אחר) למשך ההפעלה.

2. הדלקת Wireless Debugging

לחץ באפליקציה על ⚙️ פתח Developer Options והדלק את המתג Wireless debugging.

3. לחיצה על Start

לחץ על 🚀 פתח אפליקציית Shizuku ולחץ מיד על הכפתור Start.

4. חזרה וניתוק Wi-Fi

חזור לאפליקציה — הכפתור למעלה יהפוך לירוק (⚡ Shizuku פעיל). כעת ניתן לכבות Wi-Fi.

3. הכרת מסכי האפליקציה (תצוגות מסך מפורטות)

⬇
כפתורי ייצוא (CSV / JSON)

📊

5. הסבר מדדי הרדיו (RF KPIs) וזיהוי התאים

מדריך מקוצר לפענוח הערכים המופיעים במסך הראשי ובדוחות הניתוח:

מדד משמעות הנדסית ערכים תקינים / מצוינים
RSRP / RSCP עוצמת האות הנקלט מהאנטנה המשרתת (4G/5G RSRP, 3G RSCP). -65 עד -90 dBm (מעל -105 חלש)
RSRQ / Ec/No איכות האות הנקלט ביחס לעומס ולרעש בתדר. -3 עד -11 dB (מתחת ל- -15 עמוס)
SINR יחס אות לרעש והפרעות — קובע ישירות את מהירות הגלישה. מעל +13 dB (מתחת ל-0 הפרעות)
PCI / PSC מזהה הפיזי של סקטור האנטנה (0–503 ב-LTE, 0–1007 ב-5G). שינוי ב-PCI מעיד על Handover
eNB / gNB ID המספר המזהה של אתר השידור (תחנת הבסיס הפיזית). מזהה את המיקום הגיאוגרפי של האתר
ARFCN מספר ערוץ התדר המדויק שעליו משדרת האנטנה. קובע את תחום התדר (Band)
